# Balanced Perturbation Force Benchmark

This benchmark contains five configurations for each of five chemical families. Configurations were generated from converged DFT structures using fixed Gaussian displacement amplitudes and deterministic seeds. Membership was fixed before any MACE prediction, so model error did not influence selection. DFT single points use spin-polarized PBE, ENCUT=520 eV, a 3x3x1 mesh, and EDIFF=1e-6 eV.
