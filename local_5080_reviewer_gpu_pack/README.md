# Local RTX 5080 Reviewer GPU Pack

This pack is only for reviewer-response GPU tasks:

1. MACE foundation-vs-fine-tuned evaluation on train/valid/test splits.
2. Small multi-seed MACE committee training for uncertainty diagnostics.
3. LAMMPS-MACE review MD with unwrapped coordinates and multiple seeds.

Read `AGENT_REVIEWER_GPU_GUIDE.md` first. It is written for an AI coding agent
that will run this package on a local RTX 5080 workstation.

The CPU CI-NEB tasks are not in this pack; they were submitted on the cluster
CPU partition.
